# Hormuz v1.2.0: context optimization and Apple Silicon companion

Context optimization is assigned to the normal Hormuz **v1.2.0** minor release
line. v1.1.0 remains the accepted portfolio-intelligence release scope, so this
feature does not reuse that version and does not create an experiment version.
The v1.1.0 portfolio milestone remains independently gated; this release does
not claim that milestone's unfinished connectors, scorecards, recommendations,
external validation, or finance reconciliation.

The v1.2.0 feature adds a default-Off, per-device/per-profile toggle, four
bounded lossless tool-result representations, a launcher-owned authenticated
loopback relay for Codex and Claude Code, offline inspection/evaluation tools,
and a gateway decoder used only to preserve existing secret enforcement. It
adds no gateway optimizer, tokenizer, content store, prompt telemetry, provider
route, or policy setting.

The native Mac companion now packages that helper for Apple Silicon, keeps the
Hormuz session in Keychain, and exposes connection, client, context, usage, and
appearance controls in its right-edge surface. The supported direct-download
boundary is macOS 14 or later on `arm64`. Intel builds and Intel qualification
are intentionally absent.

Source users can install the gateway without the tokenizer dependency. From the
v1.2.0 source tree, the optional local feature uses `pip install '.[context]'`
followed by the explicit `hormuz context resources install` step. Model request handling
never downloads resources. The notarized Mac archive contains the matching
helper and its verified tokenizer files, so Mac users do not install Python.

Release-candidate evidence establishes local behavior. Publication still requires
exact-candidate CI and review, a signed Apple Silicon
Mac artifact with one signed arm64 helper plus bundled verified tokenizer
resources, clean package installation, supported-client acceptance, paired
model-quality results under an authorized budget, and normal publication
authorization. Release evidence must identify which of those gates passed and
must not turn a pending external gate into a claim.
