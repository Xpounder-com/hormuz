# Hormuz v1.4.0: Native client baseline

Hormuz v1.4.0 preserves the stable v1 CLI and policy/evidence contracts and the
v1.3 Personal Optimizer. It aligns the Python package, gateway image and Mac
companion on one release version.

This release records repeated Apple Silicon companion footprint observations
from the v1.3 notarized app and adds regression budgets for that measured
scope. Windows CI builds and observes the existing native shell in explicit
synthetic preview mode, with a repeat-build check and content-free evidence.
The shared Rust contracts and Windows development source remain available for
further native-client work.

Install the released Python archive with:

```sh
python -m pip install 'hormuz[client,context] @ https://github.com/Xpounder-com/hormuz/releases/download/v1.4.0/hormuz-1.4.0-py3-none-any.whl'
hormuz context resources install
hormuz personal contract --json
hormuz personal qualify --json
```

The signed and notarized Mac archive is for Apple Silicon on macOS 14 or later.
The Windows executable is an unsigned development preview, not a supported
installer or a connected-product release. Automated UI Automation, synthesized
tray input and display fixtures do not replace manual keyboard, tray,
screen-reader or physical display/DPI acceptance. Those checks remain in
[#331](https://github.com/Xpounder-com/hormuz/issues/331); sign-in and real
Windows usage are separate later milestones.

Package, macOS distribution and signed OCI evidence are attached to the
[v1.4.0 release](https://github.com/Xpounder-com/hormuz/releases/tag/v1.4.0).
The release does not claim live-provider savings, independent customer
acceptance or production certification.
