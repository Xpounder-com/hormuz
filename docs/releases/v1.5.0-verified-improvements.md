# Hormuz v1.5.0: Verified improvements; Windows preview

Hormuz v1.5.0 preserves the stable v1 CLI and policy/evidence contracts and
the Personal Optimizer, adapter SDK and Aider integration. The Python package
and signed Linux AMD64 gateway image use one release identity.

## Included improvements

- Gateway desktop enrollment and account-discovery contracts support the
  browser-authenticated Mac sign-in work. Provider-free tests cover profile
  binding, discovery authorization and session error handling. This does not
  publish the newer Mac UI or establish a deployed hosted sign-in flow.
- The website uses Next.js 16.3.8, with the dependency security update and
  current Personal Optimizer and hosted-service setup guidance.
- Windows development source connects input, output and cost detail cards to
  the shared interaction reducer. Native CI checks the detail content,
  unchanged metric positions, focus/state transitions and repeat-build identity.
  Synthetic footprint evidence covers preview idle modes, not real connected
  workloads.

## Install and verify

```sh
python -m pip install 'PyJWT[crypto]>=2.14,<3' 'hormuz[client,context] @ https://github.com/Xpounder-com/hormuz/releases/download/v1.5.0/hormuz-1.5.0-py3-none-any.whl'
hormuz context resources install
hormuz personal contract --json
hormuz personal qualify --json
```

The explicit PyJWT requirement also upgrades older compatible installations;
the signed OCI image pins PyJWT 2.15.1. The release's `SHA256SUMS.txt` binds
the wheel, source archive and content-free signed OCI evidence. For the Linux
AMD64 image, pin the digest from `oci-release-summary.json` and follow
[the signature-verification instructions](../OCI.md).

## Platform boundaries

**Windows remains an unsigned, unsupported development preview.** Native
source and automated tests are not a supported installer, physical desktop
acceptance or proof of real account sign-in. The Rust Windows package remains
`1.5.0-dev.1`. No signed Windows installer is published in this core release.
Authorized sign-in and real scoped usage, actual Credential Manager denial,
keyboard/screen-reader/tray interaction, display/DPI behavior, clean-machine
installation and connected footprint remain open in
[#331](https://github.com/Xpounder-com/hormuz/issues/331) and #337–#339, with
the [connected-product gate in #340](https://github.com/Xpounder-com/hormuz/issues/340).
Preview publication does not close those issues or complete the native roadmap.

The latest Developer ID signed and notarized Mac archive remains
[v1.3.0 for Apple Silicon on macOS 14+](https://github.com/Xpounder-com/hormuz/releases/download/v1.3.0/Hormuz-1.3.0-notarized.zip).
No v1.5 Mac app is submitted to Apple or published here. Linux OCI support
remains `linux/amd64`; native Linux desktop and ARM64 qualification are separate.

This release does not claim live-provider savings, independent customer
acceptance, deployment activation or general production certification.
Package hashes, the protected release commit, CI runs and signed image evidence
are recorded on the [v1.5.0 release](https://github.com/Xpounder-com/hormuz/releases/tag/v1.5.0).
