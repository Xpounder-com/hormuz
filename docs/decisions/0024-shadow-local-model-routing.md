# ADR 0024: Keep local model routing advice observational

The owner requested a local routing model in shadow mode on October 15, 2026.
Keep admission, privacy and successful conversation affinity authoritative while
measuring the model's advice against real coding checks. A model's own claim of
confidence cannot establish its coding capability or permission to send work away.

Attach versioned content-free advice to existing AI Work attempts. Reuse the
verified local runtime and one inference lease, with explicit opt-in and bounded
classification. This preserves useful historical comparisons without a second
learning ledger, prompt store or new coding app. The additive evidence and
rollback rules are in [shadow routing](../SHADOW_ROUTING.md); live learned routing
requires a separate evidence-backed decision.
