# ADR 0029: Collect coding outcomes through explicit bounded local probes

Ordinary unqualified coding must remain blocked, while a first honest outcome
campaign needs an execution path. Add ephemeral, operator-invoked permission to
the shared connected-client owner rather than weakening automatic admission or
installing invented passing evidence. Bind one frozen case, request profile,
actor, native conversation and managed local generation with finite request and
time budgets. This grants neither readiness nor learned routing authority.
Existing policy, privacy, affinity and owned cleanup remain authoritative.

The [bounded probe contract](../BOUNDED_CODING_PROBES.md) records the public
workflow, operator trust boundary, no-replay rule and rollback behavior.
Outcomes remain separate from permission; reviewed evidence under ADR 0025
remains the automatic coding qualification path.
