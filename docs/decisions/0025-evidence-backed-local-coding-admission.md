# ADR 0025: Require outcome evidence for automatic local coding admission

The shipped operator envelope describes coding transport despite unsuccessful
native repairs. Require a pinned, predeclared campaign with actual edits,
independent checks and normal completion before fresh automatic coding admission;
keep health and shadow advice observational. Explicit declarations remain useful
for noncoding work and experiments, but cannot silently become coding evidence.

The first criteria cover bounded autonomous repairs, with development/held-out
separation and no qualified code review. This deliberately trades local coverage
for truthful readiness and fail-closed privacy. The versioned contract, trust
limits, acceptance floor and migration rules are in
[local coding qualification](../LOCAL_CODING_QUALIFICATION.md).
