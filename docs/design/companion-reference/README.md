These unchanged upstream files preserve the visual target and measured constants
for the Hormuz companion implementation. They are reference documentation, not
code included in the Hormuz build. Retain the license/attribution when adapting
substantial portions. The design frames contain upstream branding and desktop
imagery; do not ship those images or logos as Hormuz assets.

Start with [the visual execution specification](../../DESKTOP_COMPANION_VISUAL_SPEC.md).
The upstream measurements use design pixels times `44/117` to obtain logical
points. The screenshots are 2000 × 2000 pixels, not native 1× macOS screenshots.
The snapshot is deliberately partial; source files may reference omitted types.
