# Archived schema-v2 observations

These nine JSON files are the unmodified collector outputs from the signed
Mac v1.2.0 synthetic-preview repeats. Their `rusage_cpu_time_ns_sum` field is
**mislabeled**: Darwin `proc_pid_rusage` returns Mach absolute-time ticks for
`ri_user_time` and `ri_system_time`. Consequently, the files' derived
`rusage_cpu_percent_of_one_core` values are **incorrect** and must not be
quoted as CPU results.

The sibling schema-v3 reports are generated by `normalize_macos_idle.py`,
which records each raw file's SHA-256, renames the raw tick field and applies
this host's measured `mach_timebase_info` ratio of 125/3. The conversion
changes no observed sample value. `verify_repeats.py` recomputes every sibling
report from its archived source and rejects any mismatch. Only runs with one
continuously checked root process at every sample were accepted, because this
v2 format did not retain helper identities needed to validate cumulative
counter deltas across process-topology changes.

The first hidden recording was excluded from this archive: AC power changed to
battery during that run, a window probe ran during its sample, and it used the
earlier schema-v1 collector. A new hidden recording with battery power at both
boundary checks replaces it in the comparable set.
