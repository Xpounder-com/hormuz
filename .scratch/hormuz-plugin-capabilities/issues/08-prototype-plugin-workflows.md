## Question

What interaction model makes the chosen workflows understandable with minimal setup? Prototype focused skill entry points, structured operation results, and a compact status/explanation view as appropriate. Have the user react to rough artifacts before deciding boundaries among chat, CLI and optional interface. Apply the prototype skill; do not implement production UI.
