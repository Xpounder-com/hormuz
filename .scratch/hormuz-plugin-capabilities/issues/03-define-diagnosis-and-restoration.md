# Define diagnosis and restoration guarantees

Id: 03
Parent: [Find the way to Hormuz’s next plugin release](../map.md)
Type: grilling
Labels: wayfinder:grilling
Status: open
Assignee: none
Blocked by: 01

## Question

Which failures must Hormuz distinguish, which recovery actions may it recommend or perform, and what evidence proves restoration? Cover client compatibility, router versus model readiness, configuration overrides, occupied resources, interrupted setup, user edits after connection, and owned versus external processes. Specify the useful recovery output and boundaries of automatic read-only checks.
